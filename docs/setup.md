# Setup

## 1. Create Grafana Cloud connection

In Grafana Cloud, OpenTelemetry connection details were generated.

The following values were used by Grafana Alloy:

```
Grafana Cloud OTLP / Metrics endpoint
Grafana Cloud instance ID
Grafana Cloud access token
```

These credentials were generated in Grafana Cloud Collector Setup.

## 2. Create EC2 instance for Grafana Alloy

An EC2 instance was created manually.

Configuration:
```
Name: grafana-alloy-collector
AMI: Ubuntu Server 24.04 LTS
Instance type: t3.micro
Region: eu-north-1
Architecture: x86_64
Storage: 8 GiB gp3
Public IPv4: X.X.X.X
```

## 3. Configure Security Group

Inbound rules:

```
SSH          TCP 22    My IP
Custom TCP   TCP 4318  0.0.0.0/0
```

Port 4318 is required because Lambda sends OTLP/HTTP telemetry to Grafana Alloy.

## 4. Install Grafana Alloy

Grafana Alloy was installed on EC2 using the command generated by Grafana Cloud Collector Setup.

After installation, the service was checked:

```
sudo systemctl status alloy
```

Expected result:

```
active (running)
```

The OTLP port was checked:

```
sudo ss -tulpen | grep 4318
```

Expected result:

```
Alloy is listening on port 4318
```

## 5. Configure Alloy

Alloy was configured to receive OTLP data from Lambda on port 4318.

Example:
```
otelcol.receiver.otlp "lambda" {
  http {
    endpoint = "0.0.0.0:4318"
  }

  output {
    metrics = [otelcol.processor.batch.lambda.input]
  }
}
```

## 6. Configure Lambda environment variables

In AWS Lambda, the following environment variables were added:

```
OTEL_SERVICE_NAME=go-lambda-demo
OTEL_EXPORTER_OTLP_ENDPOINT=http://X.X.X.X:4318
OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
OTEL_RESOURCE_ATTRIBUTES=service.namespace=aws-lambda,deployment.environment=production
```

The most important variable is:

```
OTEL_EXPORTER_OTLP_ENDPOINT=http://X.X.X.X:4318
```

It points the Lambda function to the EC2 instance where Grafana Alloy is running.

## 7. Build Go Lambda function

```
cd lambda-function
go mod tidy
GOOS=linux GOARCH=amd64 go build -o bootstrap main.go
zip function.zip bootstrap
```

## 8. Upload Lambda code
```
aws lambda update-function-code \
  --function-name Test2 \
  --zip-file fileb://function.zip \
  --region eu-north-1
```

## 9. Test Lambda

```
{
  "message": "Hello, Stepan"
}
```

To simulate an error metric:

```
{
  "name": "error"
}
```

## 10. Check metrics in Grafana

In Grafana Explore, the following metrics were checked:

```
lambda_invocations_total
lambda_errors_total
lambda_duration_ms_count
```

If these metrics appear, the full pipeline works:

```
Lambda → OTLP/HTTP → EC2 Alloy → Grafana Cloud
```
